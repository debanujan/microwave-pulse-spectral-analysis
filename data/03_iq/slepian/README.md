# Slepian I and II: IQ Time-Domain Data

This folder is for the Slepian I and II CSV files from the iq time-domain data stage. Filenames begin with `03_iq_slepian_`.

The two DPSS tapers are stored in separate columns of the same CSV file.

CSV files for different simulation parameters are kept together here, with their original filenames and column headers.

See the [stage index](../README.md) and [data guide](../../README.md) for the organisation of the outputs.
