# Hann, Hamming and Blackman: IQ Spectral Data

This folder is for the Hann, Hamming and Blackman CSV files from the iq spectral data stage. Filenames begin with `04_iq_fft_raised_cosines_`.

The three envelopes are stored in separate columns of the same CSV file.

CSV files for different simulation parameters are kept together here, with their original filenames and column headers.

See the [stage index](../README.md) and [data guide](../../README.md) for the organisation of the outputs.
