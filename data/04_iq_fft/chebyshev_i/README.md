# Chebyshev I: IQ Spectral Data

This folder is for the Chebyshev I CSV files from the iq spectral data stage. Filenames begin with `04_iq_fft_chebyshev_I_`.

CSV files for different simulation parameters are kept together here, with their original filenames and column headers.

See the [stage index](../README.md) and [data guide](../../README.md) for the organisation of the outputs.
