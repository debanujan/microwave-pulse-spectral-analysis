# Hann, Hamming and Blackman: IQ Time-Domain Plots

This folder is for the Hann, Hamming and Blackman PNG figures from the iq time-domain plots stage. Filenames begin with `03_iq_raised_cosines_`.

Hann, Hamming and Blackman are shown together in the same figure.

Figures for different simulation parameters are kept together here, with their original filenames.
