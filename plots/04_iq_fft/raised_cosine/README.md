# Hann, Hamming and Blackman: IQ Spectra

This folder is for the Hann, Hamming and Blackman PNG figures from the iq spectra stage. Filenames begin with `04_iq_fft_raised_cosines_`.

Hann, Hamming and Blackman are shown together in the same figure.

Figures for different simulation parameters are kept together here, with their original filenames.
