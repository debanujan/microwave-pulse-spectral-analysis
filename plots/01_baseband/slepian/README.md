# Slepian I and II: Baseband Pulse Plots

This folder is for the Slepian I and II PNG figures from the baseband pulse plots stage. Filenames begin with `01_baseband_slepian_`.

Slepian I and II are shown together in the same figure.

Figures for different simulation parameters are kept together here, with their original filenames.

See the [stage index](../README.md), [figure guide](../../README.md) and [corresponding numerical data](../../../data/01_baseband/slepian/).
