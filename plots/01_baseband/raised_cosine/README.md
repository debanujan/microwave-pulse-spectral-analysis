# Hann, Hamming and Blackman: Baseband Pulse Plots

This folder is for the Hann, Hamming and Blackman PNG figures from the baseband pulse plots stage. Filenames begin with `01_baseband_raised_cosines_`.

Hann, Hamming and Blackman are shown together in the same figure.

Figures for different simulation parameters are kept together here, with their original filenames.
