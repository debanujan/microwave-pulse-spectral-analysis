# Hann, Hamming and Blackman: Baseband Spectra

This folder is for the Hann, Hamming and Blackman PNG figures from the baseband spectra stage. Filenames begin with `02_baseband_fft_raised_cosines_`.

Hann, Hamming and Blackman are shown together in the same figure.

Figures for different simulation parameters are kept together here, with their original filenames.
